# Creating Classes and Objects

## Description

This Java program demonstrates classes and objects using a Rectangle class.

## Features

* Stores length and width.
* Calculates area and perimeter.
* Creates multiple Rectangle objects.

## Formulas

* Area = Length × Width
* Perimeter = 2 × (Length + Width)

## Concepts Used

* Classes and Objects
* Attributes
* Constructor
* Methods

## Language

Java
